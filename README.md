# beevast-releases

Public mirror for BeeVast install.sh + binary releases.
Source code lives in the private `yoyo20260321/beevast` repo.

## One-line install

```bash
curl -fsSL https://raw.githubusercontent.com/yoyo20260321/beevast-releases/main/install.sh | bash
```

Specific env / channel:

```bash
BEEVAST_ENV=pre1 BEEVAST_CHANNEL=beta \
  curl -fsSL https://raw.githubusercontent.com/yoyo20260321/beevast-releases/main/install.sh | bash
```
